# Linux System Administration & Shell Utilities

## Overview
This repository contains Linux system administration scripts, user access control configurations, package maintenance procedures, and network troubleshooting workflows.

## Key Features & Highlights
* **User & File Access Management**: Demonstrated account creation (`useradd`), group assignments (`usermod`), ownership configuration (`chown`), and Discretionary Access Control (DAC) permission restrictions (`chmod 600`).
* **Package Maintenance & Troubleshooting**: Defined standard system update workflows using `apt update` and `apt full-upgrade` alongside `sudo` privilege management.
* **Network Interface Configuration**: Configured interface states (`ip link`), dynamic IP resolution (`dhclient`), default gateway routes (`ip route`), and structured bottom-up network diagnostics.
